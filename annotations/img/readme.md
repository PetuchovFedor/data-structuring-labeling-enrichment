**Аннотирование проводилось по строчно, для каждого строки заполнялись атрибуты представленные в таблице**

| Атрибут | Обязательность | Допустимые значения | Пояснение |
|---------|----------------|---------------------|-----------|
| `AuthorId` | Обязательно | Целое число от 0 до 199 | Идентификатор автора рукописи. |
| `Slant` | Обязательно | `left`, `right`, `mixed`, `vertical` | Преобладающий наклон букв в строке. `right` — вправо, `left` — влево, `vertical` — вертикальный, `mixed` — наклон меняется внутри строки. |
| `LetterSize` | Обязательно | `small`, `medium`, `large` | Преобладающий размер строчных букв. `small` — мелкий, `medium` — средний, `large` — крупный. |
| `Connectivity` | Обязательно | `low`, `medium`, `high` | Степень связности букв в строке. `high` — большинство букв соединены, `medium` — примерно половина, `low` — буквы пишутся раздельно. |
| `Pressure` | Обязательно | `weak`, `medium`, `strong` | Сила нажима пера. Определяется по толщине штрихов и интенсивности чернил. `strong` — толстые тёмные штрихи, `weak` — тонкие светлые. |
| `Spacing` | Обязательно | `narrow`, `medium`, `wide` | Интервалы между буквами и словами. `narrow` — плотное письмо, `wide` — разреженное. |
